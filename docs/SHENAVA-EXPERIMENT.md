# Shenava Persian ASR evaluation (experimental; not shipped)

This branch does **not** replace Whisper in the Android app. It establishes a reproducible gate before adding a second native runtime. The existing Android application ID, project files, model cache and user settings are untouched.

## Candidate
- Canonical model: Reza2kn/Shenava-Koochik-v1.0-sherpa-onnx (Apache-2.0 metadata and LICENSE; recheck the exact revision and upstream dependencies before redistribution).
- Offline FastConformer CTC, model.onnx + tokens.txt; ~459 MB FP32 model.
- 16 kHz mono waveform. Do not enable sherpa-onnx per-feature normalization: model metadata leaves normalize_type empty.
- No reliable per-word timestamps are guaranteed by this CTC output. Do not synthesize them or replace the app's current Whisper word alignment without separate evaluation.
- RNNT v1.5 is an independent candidate, **not** interchangeable with this CTC runner; it requires encoder/decoder/joiner and model_type=nemo_transducer. Its author reports higher WER than CTC on golden-6669.

## Local comparison
Install sherpa-onnx, numpy and soundfile in an isolated Python environment. Download the canonical model files yourself into a local directory; never commit models or private audio.

Create a CSV with `wav,reference,whisper` columns. Each WAV must be 16 kHz mono; `whisper` is the transcript from the *same* clip generated by the current Android release. The script does not call Whisper or upload any audio.

```bash
python scripts/benchmark_shenava.py --model-dir /models/shenava-ctc --manifest /private/persian-test.csv --output /private/shenava-results.json
```

Compare aggregate WER/CER **only** when every clip has both transcripts, using identical references and text normalization. Record model load time, peak RAM, RTF, crashes, silence/music hallucinations, speaker overlap and timing separately on physical arm64 Android hardware. The script measures per-file decoding wall time but not Android RAM or subtitle alignment.

**Promotion gate:** better matched-corpus WER/CER without worse hallucinations; Android offline inference succeeds under memory budget; valid RTL text; preserve silence gaps and word timing or fall back to Whisper; Android tests and release build succeed. No release/version bump until all gates pass.
